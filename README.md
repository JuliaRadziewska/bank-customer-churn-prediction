# Bank Customer Churn Prediction

This project focuses on predicting customer churn in a banking dataset using multiple classification models. The goal was to identify customers likely to leave the bank (churn).

Customer churn provides companies with an understanding of customer loyalty and directs attention to areas that are causing customers to leave. It is often used as one of the key business metrics.

## Tools

Python, Pandas, Numpy, Scikit-learn, XGBoost, Matplotlib, Seaborn

## Models

* Logistic Regression
* Decision Tree
* Random Forest
* XGBoost

## Workflow

* Data cleaning
* Exploratory Data Analysis (EDA)
* Data preprocessing and feature encoding
* Model training and hyperparameter tuning
* Model evaluation using F1-score, Precision, Recall, ROC-AUC, and confusion matrices

## Results

**Random Forest** achieved the best overall performance:

* F1-score: 0.595
* Precision: 0.571
* Recall: 0.622
* ROC-AUC: 0.856
